# Tariq Book Depot design system

The visual language is archival paper, ink, stone, and physical bookstore craft. Headlines use Newsreader; interface text uses Plus Jakarta Sans. Use logical CSS properties so Urdu RTL layouts mirror correctly.

## Guardrails

- Keep commerce 2D and fast; reserve 3D for an opt-in hero/inspection enhancement.
- Do not invent reviews, sales metrics, prices, stock, policies, or contact details.
- Use semantic controls, visible focus rings, reduced-motion fallbacks, and touch targets of at least 44px.
- Avoid decorative gradients, emoji controls, repetitive uppercase labels, and fake forms.

Locked tokens live in `apps/storefront/src/styles/tokens.css`.
