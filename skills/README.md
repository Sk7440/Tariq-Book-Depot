# Stored Agent Skills

This directory contains independent copies of the GitHub repositories and attached skill supplied for Tariq Book Depot.

| Folder | Source | Coverage |
|---|---|---|
| `web-design-engineer/` | `mysteve/web-design-skill` | Anti-cliché web design, design-system declaration, and advanced component patterns |
| `web-design/` | `xiaopu-ai/web-design` | Spec-first `DESIGN.md` workflow, style systems, motion, quality auditing, and reference crawling |
| `premium-web-design/` | `Lucxar/premium-web-design-skill` | Premium visual hierarchy, design tokens, brand patterns, and evidence-led design |
| `animation/` | `iart-ai/web-animation-skills` | GSAP, 60fps motion, page transitions, accessibility, micro-interactions, glassmorphism, SVG, Lottie, and ASCII |
| `micro-interaction/` | Attached `micro-interaction/SKILL.md` plus iart.ai references | Focused UI feedback motion in CSS and Framer Motion |
| `data-animation/` | `iart-ai/data-animation-skills` | Animated charts, infographics, and presentation videos |
| `gsap/` | `greensock/gsap-skills` | Official GreenSock core, timelines, ScrollTrigger, plugins, React, frameworks, utilities, and performance |
| `gsap-framer-scroll-animation/` | `github/awesome-copilot` | GitHub Copilot recipes and references for GSAP and Framer Motion scroll animation |

## License

Preserve each repository's own `LICENSE` or upstream license notice. The stored third-party repositories are MIT-licensed sources; they are not presented as original Tariq Book Depot code. `premium-web-design/` did not contain a standalone license file in the source repository, although its README identified the project as MIT-licensed.

## Usage

Read only the relevant `SKILL.md` and referenced files during a design or animation task. Avoid applying multiple motion philosophies to the existing storefront at once. The Tariq Book Depot [Copilot instructions](../.github/copilot-instructions.md) remain the project-specific source of truth for commerce, accessibility, and design invariants.
